## 2. Назначение и цели создания системы

| Пункт | Содержание |
|-------|------------|
| 2.1. Назначение системы | Вычисление чисел Фибоначчи и фигурных чисел (десятиугольных) по запросу пользователя |
| 2.2. Цели создания системы | Предоставление пользователю удобного инструмента для быстрого и корректного расчёта указанных числовых последовательностей через командно-строчный интерфейс |

## 3. Характеристика объектов автоматизации

Объектом автоматизации является процесс ручного вычисления математических последовательностей, который может быть подвержен ошибкам и требует значительного времени.

## 4. Требования к системе

### 4.1. Требования к системе в целом

| ID | Требование |
|----|------------|
| 4.1.1 | Система реализуется на языке Python 3 и состоит из `main.py`, `math_utils.py` и `fibonacci_module.py`. Главный модуль вызывает функции из других файлов |
| 4.1.2 | Взаимодействие через командную строку (CLI): пользователь передаёт команду аргументом, затем вводит число N в стандартный ввод; система выводит результат и завершается |
| 4.1.3 | Для эксплуатации системы не требуется специальной квалификации персонала |

### 4.2. Требования к функциям, выполняемым системой

| ID | Требование |
|----|------------|
| 4.2.1 | Вычисление N-го числа Фибоначчи для целого неотрицательного N (F(0)=0, F(1)=1) |
| 4.2.2 | Вычисление N-го десятиугольного числа для целого неотрицательного N по формуле P(n) = n(8n − 6) / 2 |
| 4.2.3 | Обработка ошибок: пустая строка, наличие нецифровых символов в строке числа, N > 100000, неизвестная команда, неверное количество аргументов. В каждом случае — понятное сообщение и код возврата 1 |
| 4.2.4 | Функциональные характеристики: команды `fib` и `dec`; диапазон 0 ≤ N ≤ 100000; строка числа должна состоять только из цифр 0-9 (пробелы по краям обрезаются), иначе — ошибка |

### 4.3. Требования к видам обеспечения

| ID | Вид обеспечения | Требование |
|----|-----------------|------------|
| 4.3.1 | Математическое | Реализация формул F(n) = F(n−1) + F(n−2) и P(n) = n(8n − 6) / 2 |
| 4.3.2 | Программное | Интерпретатор Python 3.6+; внешние библиотеки не используются |
| 4.3.3 | Информационное | Данные не хранятся между сессиями |
