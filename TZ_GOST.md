# Техническое Задание на создание программы "fibdec-calculator"

(Составлено на основе ГОСТ 34.602-2020)

## 1. Общие сведения

*   **1.1. Полное наименование системы:** Программное изделие "fibdec-calculator".
*   **1.2. Условное обозначение:** AW-CALC.
*   **1.3. Заказчик:** Шмаков И.А.
*   **1.4. Исполнитель:** Цымбалюк Д.С.
*   **1.5. Основание для разработки:** Учебное задание (лабораторная работа №1 по дисциплине «Анализ данных и системная аналитика»).

## 2. Назначение и цели создания системы

*   **2.1. Назначение системы:** Программа предназначена для вычисления чисел Фибоначчи и фигурных чисел (десятиугольных) по запросу пользователя.
*   **2.2. Цели создания системы:** Предоставление пользователю удобного инструмента для быстрого и корректного расчёта указанных числовых последовательностей через командно-строчный интерфейс.

## 3. Характеристика объектов автоматизации

Объектом автоматизации является процесс ручного вычисления математических последовательностей, который может быть подвержен ошибкам и требует значительного времени.

## 4. Требования к системе

### 4.1. Требования к системе в целом

*   **4.1.1. Требования к структуре и функционированию системы:** Система должна быть реализована на языке Python 3 и состоять из основного исполняемого файла (`main.py`) и модулей (`math_utils.py`, `fibonacci_module.py`). Главный модуль должен вызывать функции из других файлов.
*   **4.1.2. Требования к взаимодействию с пользователем:** Взаимодействие должно осуществляться через командную строку (CLI). Пользователь вводит команду и число, система выводит результат и завершается.
*   **4.1.3. Требования к численности и квалификации персонала:** Для эксплуатации системы не требуется специальной квалификации.

### 4.2. Требования к функциям, выполняемым системой

*   **4.2.1. Вычисление чисел Фибоначчи:** Система должна принимать на вход целое неотрицательное число N и возвращать N-е число Фибоначчи (F(0)=0, F(1)=1).
*   **4.2.2. Вычисление десятиугольных чисел:** Система должна принимать на вход целое неотрицательное число N и возвращать N-е десятиугольное число по формуле P(n) = n(8n − 6) / 2.
*   **4.2.3. Обработка ошибок:** Система должна корректно обрабатывать некорректный пользовательский ввод, а именно:
    *   отсутствие цифр во введённой строке (например, `abc`);
    *   превышение верхней границы N > 100000;
    *   неизвестная команда (не `fib` и не `dec`);
    *   неверное количество аргументов командной строки.
    В каждом из этих случаев система должна выводить понятное сообщение и завершаться с ненулевым кодом возврата.
*   **4.2.4. Функциональные характеристики:**
    *   команды: `fib`, `dec`;
    *   диапазон N: 0 ≤ N ≤ 100000;
    *   все нецифровые символы во входной строке игнорируются (например, `12a3` трактуется как `123`).

### 4.3. Требования к видам обеспечения

*   **4.3.1. Математическое обеспечение:** Должны быть реализованы формулы для вычисления чисел Фибоначчи (F(n) = F(n−1) + F(n−2)) и десятиугольных чисел (P(n) = n(8n − 6) / 2).
*   **4.3.2. Программное обеспечение:** Для работы требуется интерпретатор Python версии 3.6 или выше. Внешние библиотеки не используются.
*   **4.3.3. Информационное обеспечение:** Данные не хранятся между сессиями.
