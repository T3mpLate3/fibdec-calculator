# Спецификация Системных Требований (SyRS) для "fibdec-calculator"

(На основе ISO/IEC/IEEE 29148-2011)

## 1. Введение

### 1.1. Цель документа
Документ описывает требования к системе "fibdec-calculator" на уровне взаимодействия человек–система, окружения и ограничений. Детализация до уровня функций приведена в `SRS_IEEE.md`.

### 1.2. Область применения
Система представляет собой консольное приложение на Python 3 для вычисления чисел Фибоначчи и десятиугольных чисел.

### 1.3. Аудитория
Заказчик, разработчик, тестировщик, преподаватель.

### 1.4. Соглашения
*   **SyRS** — System Requirements Specification.
*   **SRS** — Software Requirements Specification.
*   **CLI** — Command-Line Interface.

## 2. Описание системы

### 2.1. Назначение системы
Предоставить пользователю утилиту командной строки для быстрого вычисления N-го числа Фибоначчи и N-го десятиугольного числа.

### 2.2. Пользователи системы
Целевой пользователь — человек, знакомый с основами работы в командной строке. Специальной подготовки не требуется.

### 2.3. Сценарии использования (Use Cases)

| ID | Название | Действие пользователя | Ожидаемый результат |
|----|----------|----------------------|---------------------|
| UC-1 | Вычисление числа Фибоначчи | `python3 main.py fib`, затем ввод `10` | Вывод `Число Фибоначчи для N=10: 55`, код возврата 0 |
| UC-2 | Вычисление десятиугольного числа | `python3 main.py dec`, затем ввод `5` | Вывод `Десятиугольное число для N=5: 85`, код возврата 0 |
| UC-3 | Ошибочный ввод числа (буквы) | `python3 main.py fib`, затем ввод `12a3` | Сообщение об ошибке, код возврата 1 |
| UC-4 | Ошибочный ввод числа (пустая строка) | `python3 main.py dec`, затем ввод (пусто) | Сообщение об ошибке, код возврата 1 |
| UC-5 | Превышение лимита | `python3 main.py fib`, затем ввод `100001` | Сообщение об ошибке, код возврата 1 |
| UC-6 | Неизвестная команда | `python3 main.py bad` | Сообщение «Неизвестная команда» и подсказка, код возврата 1 |
| UC-7 | Отсутствие аргументов | `python3 main.py` | Сообщение «Неверное количество аргументов» и подсказка, код возврата 1 |
| UC-8 | Прерывание ввода | `python3 main.py fib`, затем `Ctrl+D` или `Ctrl+C` | Сообщение «Ввод прерван», код возврата 1 |

### 2.4. Среда функционирования

| Параметр | Значение |
|----------|----------|
| Операционная система | Windows, macOS, Linux |
| Среда исполнения | Python 3.6+ |
| Внешние библиотеки | Не требуются |

## 3. Требования к системе

### 3.1. Требования к взаимодействию человек–система

| ID | Требование |
|----|------------|
| SR-1 | Взаимодействие через командную строку: `python3 main.py <команда>`, затем ввод числа N в стандартный ввод |
| SR-2 | При неверном количестве аргументов система выводит сообщение об ошибке и подсказку по использованию |
| SR-3 | Сообщения об ошибках понятны и указывают причину: «содержит недопустимые символы», «пустая строка», «слишком большое число», «неизвестная команда» |
| SR-4 | При успехе система завершается с кодом 0, при ошибке — с кодом 1 |
| SR-5 | При неизвестной команде система выводит список доступных команд |
| SR-6 | При прерывании ввода (`Ctrl+D`, `Ctrl+C`) выводится сообщение «Ввод прерван» и код возврата 1 |

### 3.2. Требования к производительности

| ID | Требование | Критерий проверки |
|----|------------|-------------------|
| SR-7 | Время вычисления для N ≤ 1000 | Не более 1 с |
| SR-8 | Время вычисления для N ≤ 100000 | Не более 5 с |

### 3.3. Ограничения системы

| ID | Ограничение |
|----|-------------|
| SR-9 | Диапазон допустимых значений: 0 ≤ N ≤ 100000 |
| SR-10 | Не используются внешние библиотеки, кроме стандартной библиотеки Python |
| SR-11 | Данные не сохраняются между сессиями |
