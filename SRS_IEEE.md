# Спецификация Требований к Программному Обеспечению (SRS) для "fibdec-calculator"

(Составлено на основе ISO/IEC/IEEE 29148-2011)

## 1. Введение

### 1.1. Цели
Документ определяет функциональные и нефункциональные требования к программному изделию "fibdec-calculator". Системные требования более высокого уровня приведены в `SyRS_IEEE.md`.

### 1.2. Соглашения о терминах
*   **Числа Фибоначчи:** Последовательность, в которой каждое последующее число равно сумме двух предыдущих (F(0)=0, F(1)=1).
*   **Десятиугольные числа:** Фигурные числа, которые можно представить в виде десятиугольника.
*   **CLI:** Command-Line Interface.

### 1.3. Предполагаемая аудитория
Разработчики, тестировщики, заказчик проекта.

### 1.4. Масштаб проекта
Простое консольное приложение для вычислений.

## 2. Общее описание

### 2.1. Видение продукта
"fibdec-calculator" — утилита командной строки для быстрого вычисления чисел Фибоначчи и десятиугольных чисел. Продукт должен быть простым, интуитивно понятным и надёжным.

### 2.2. Функциональность продукта
Две основные функции: вычисление N-го числа Фибоначчи и вычисление N-го десятиугольного числа.

### 2.3. Классы и характеристики пользователей
Целевой пользователь — любой человек, знакомый с основами работы в командной строке.

### 2.4. Среда функционирования продукта
*   ОС: Windows, macOS, Linux.
*   Среда исполнения: Python 3.6+.

### 2.5. Рамки, ограничения, правила и стандарты
*   Приложение не должно использовать внешние библиотеки, кроме стандартных библиотек Python.
*   Код должен соответствовать стандарту PEP 8.

### 2.6. Допущения и зависимости
*   Предполагается, что у пользователя установлен Python 3.
*   Работа приложения зависит от корректности ввода данных пользователем.

## 3. Требования к данным

*   **DR-1. Входные данные:**
    *   команда — строка, одно из значений `fib` или `dec` (регистр не важен);
    *   число N — строка, из которой извлекаются только цифровые символы.
*   **DR-2. Выходные данные:**
    *   при успехе — строка формата `Число Фибоначчи для N=<N>: <результат>` или `Десятиугольное число для N=<N>: <результат>`;
    *   при ошибке — строка, начинающаяся со слова «Ошибка».
*   **DR-3. Ограничения данных:** 0 ≤ N ≤ 100000.

## 4. Функциональные требования

### 4.1. Функциональный блок 1: Вычисление чисел Фибоначчи

*   **Описание:** Пользователь может запросить вычисление N-го числа Фибоначчи.
*   **Требования:**
    *   **FR-1.1:** Система должна принимать команду `fib` и число `N` в качестве аргументов командной строки.
    *   **FR-1.2:** Система должна вычислять N-е число Фибоначчи, где F(0)=0, F(1)=1.
    *   **FR-1.3:** Система должна выводить результат в формате: `Число Фибоначчи для N=<N>: <результат>`.
    *   **FR-1.4:** Вычисление должно выполняться функцией `calculate_fibonacci` из модуля `fibonacci_module.py`, которая, в свою очередь, вызывает `fibonacci` из `math_utils.py`.

### 4.2. Функциональный блок 2: Вычисление десятиугольных чисел

*   **Описание:** Пользователь может запросить вычисление N-го десятиугольного числа.
*   **Требования:**
    *   **FR-2.1:** Система должна принимать команду `dec` и число `N` в качестве аргументов командной строки.
    *   **FR-2.2:** Система должна вычислять N-е десятиугольное число по формуле P(n) = n(8n − 6) / 2, где P(0)=0.
    *   **FR-2.3:** Система должна выводить результат в формате: `Десятиугольное число для N=<N>: <результат>`.
    *   **FR-2.4:** Вычисление должно выполняться функцией `decagonal_number` из модуля `math_utils.py`.

### 4.3. Функциональный блок 3: Обработка ошибок

*   **FR-3.1:** При отсутствии цифр в строке числа система должна вывести сообщение об ошибке и завершиться с кодом 1.
*   **FR-3.2:** При N > 100000 система должна вывести сообщение об ошибке и завершиться с кодом 1.
*   **FR-3.3:** При неизвестной команде система должна вывести сообщение об ошибке и подсказку по использованию, завершиться с кодом 1.
*   **FR-3.4:** При неверном количестве аргументов командной строки система должна вывести сообщение об ошибке и подсказку по использованию, завершиться с кодом 1.

## 5. Требования к внешним интерфейсам

### 5.1. Интерфейсы пользователя (UX)
Интерфейс — командная строка. Пример вызова: `python main.py fib 10`.

### 5.2. Программные интерфейсы
*   `main.py` импортирует `decagonal_number` из `math_utils.py` и `calculate_fibonacci` из `fibonacci_module.py`.
*   `fibonacci_module.py` импортирует `fibonacci` из `math_utils.py`.

## 6. Нефункциональные требования

*   **NFR-1. Производительность:** Время вычисления для N ≤ 1000 не должно превышать 1 секунды; для N ≤ 100000 — не более 5 секунд.
*   **NFR-2. Надёжность:** Приложение должно корректно обрабатывать некорректный ввод, не завершаясь с необработанной ошибкой (трейсбеком).
*   **NFR-3. Удобство использования:** Сообщения об ошибках должны быть понятными для пользователя.
*   **NFR-4. Переносимость:** Приложение должно работать на Windows, macOS и Linux при наличии Python 3.6+.
