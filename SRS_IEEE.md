# Спецификация Требований к Программному Обеспечению (SRS) для "fibdec-calculator"

(Составлено на основе ISO/IEC/IEEE 29148-2011)

## 1. Введение

### 1.1. Цели
Документ определяет функциональные и нефункциональные требования к программному изделию "fibdec-calculator". Системные требования более высокого уровня приведены в `SyRS_IEEE.md`.

### 1.2. Соглашения о терминах
*   **Числа Фибоначчи:** Последовательность, в которой каждое последующее число равно сумме двух предыдущих (F(0)=0, F(1)=1).
*   **Десятиугольные числа:** Фигурные числа, которые можно представить в виде десятиугольника.
*   **CLI:** Command-Line Interface.

### 1.3. Предполагаемая аудитория
Разработчики, тестировщики, заказчик проекта.

### 1.4. Масштаб проекта
Простое консольное приложение для вычислений.

## 2. Общее описание

### 2.1. Видение продукта
"fibdec-calculator" — утилита командной строки для быстрого вычисления чисел Фибоначчи и десятиугольных чисел. Продукт должен быть простым, интуитивно понятным и надёжным.

### 2.2. Функциональность продукта
Две основные функции: вычисление N-го числа Фибоначчи и вычисление N-го десятиугольного числа.

### 2.3. Классы и характеристики пользователей
Целевой пользователь — любой человек, знакомый с основами работы в командной строке.

### 2.4. Среда функционирования продукта

| Параметр | Значение |
|----------|----------|
| ОС | Windows, macOS, Linux |
| Среда исполнения | Python 3.6+ |

### 2.5. Рамки, ограничения, правила и стандарты

| ID | Ограничение |
|----|-------------|
| CR-1 | Не используются внешние библиотеки, кроме стандартной библиотеки Python |
| CR-2 | Код должен соответствовать стандарту PEP 8 |

### 2.6. Допущения и зависимости

| ID | Допущение |
|----|-----------|
| AS-1 | У пользователя установлен Python 3 |
| AS-2 | Работа приложения зависит от корректности ввода данных пользователем |

## 3. Требования к данным

| ID | Требование |
|----|------------|
| DR-1 | Вход: команда (`fib` или `dec`, регистр не важен) и число N (строка, состоящая только из цифр 0-9; пробелы по краям обрезаются) |
| DR-2 | Выход при успехе: `Число Фибоначчи для N=<N>: <результат>` или `Десятиугольное число для N=<N>: <результат>` |
| DR-3 | Выход при ошибке: строка, начинающаяся со слова «Ошибка», либо «Ввод прерван» |
| DR-4 | Ограничение диапазона: 0 ≤ N ≤ 100000 |

## 4. Функциональные требования

### 4.1. Вычисление чисел Фибоначчи

| ID | Требование | Приоритет |
|----|------------|-----------|
| FR-1.1 | Система принимает команду `fib` аргументом командной строки | Must |
| FR-1.2 | Система запрашивает число N через стандартный ввод с приглашением `Введите число N: ` | Must |
| FR-1.3 | Система вычисляет N-е число Фибоначчи, где F(0)=0, F(1)=1 | Must |
| FR-1.4 | Результат выводится в формате `Число Фибоначчи для N=<N>: <результат>` | Must |
| FR-1.5 | Вычисление выполняет `calculate_fibonacci` из `fibonacci_module.py`, которая вызывает `fibonacci` из `math_utils.py` | Must |

### 4.2. Вычисление десятиугольных чисел

| ID | Требование | Приоритет |
|----|------------|-----------|
| FR-2.1 | Система принимает команду `dec` аргументом командной строки | Must |
| FR-2.2 | Система запрашивает число N через стандартный ввод с приглашением `Введите число N: ` | Must |
| FR-2.3 | Система вычисляет N-е десятиугольное число по формуле P(n) = n(8n − 6) / 2, где P(0)=0 | Must |
| FR-2.4 | Результат выводится в формате `Десятиугольное число для N=<N>: <результат>` | Must |
| FR-2.5 | Вычисление выполняет `decagonal_number` из `math_utils.py` | Must |

### 4.3. Обработка ошибок

| ID | Требование | Приоритет |
|----|------------|-----------|
| FR-3.1 | Если строка числа пустая или содержит нецифровые символы, выводится сообщение об ошибке, код возврата 1 | Must |
| FR-3.2 | При N > 100000 выводится сообщение об ошибке, код возврата 1 | Must |
| FR-3.3 | При неизвестной команде выводится сообщение об ошибке и подсказка, код возврата 1 | Must |
| FR-3.4 | При неверном количестве аргументов выводится сообщение об ошибке и подсказка, код возврата 1 | Must |
| FR-3.5 | При прерывании ввода (`Ctrl+D`, `Ctrl+C`) выводится сообщение «Ввод прерван», код возврата 1 | Should |

## 5. Требования к внешним интерфейсам

### 5.1. Интерфейсы пользователя (UX)

| ID | Требование |
|----|------------|
| UI-1 | Интерфейс — командная строка. Пример вызова: `python3 main.py fib`, затем ввод числа |
| UI-2 | При запросе числа выводится приглашение `Введите число N: ` |

### 5.2. Программные интерфейсы

| ID | Требование |
|----|------------|
| PI-1 | `main.py` импортирует `decagonal_number` из `math_utils.py` и `calculate_fibonacci` из `fibonacci_module.py` |
| PI-2 | `fibonacci_module.py` импортирует `fibonacci` из `math_utils.py` |

## 6. Нефункциональные требования

| ID | Категория | Требование | Критерий проверки |
|----|-----------|------------|-------------------|
| NFR-1 | Производительность | Время вычисления для N ≤ 1000 | Не более 1 с |
| NFR-2 | Производительность | Время вычисления для N ≤ 100000 | Не более 5 с |
| NFR-3 | Надёжность | Корректная обработка некорректного ввода без трейсбека | Проверка сценариев UC-3…UC-8 |
| NFR-4 | Удобство использования | Сообщения об ошибках понятны пользователю | Ручная проверка |
| NFR-5 | Переносимость | Работа на Windows, macOS, Linux при наличии Python 3.6+ | Ручная проверка на доступных ОС |
